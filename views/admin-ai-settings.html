هوش مصنوعی (OpenAI)

کلید API دستیار هوشمند سایت و ابزارهای هوشمند پنل (پیشنهاد متن محصول و تحلیل رفتار) را از اینجا وارد کنید.

کلید API
در حال دریافت…
کلید را از platform.openai.com/api-keys بسازید. بعد از ذخیره، کلید هرگز دوباره نمایش داده نمی‌شود (فقط چهار نویسهٔ آخر). برای تغییر، کلید تازه را وارد کنید؛ خالی گذاشتن یعنی بدون تغییر.
خالی = مدل پیش‌فرض (gpt-4o-mini).
نکته‌های امنیتی
  • کلید در دیتابیس رمزنگاری‌شده ذخیره می‌شود و به مرورگر برنمی‌گردد.
  • این صفحه فقط برای ادمین است. کلید را در گفتگو، پیامک یا اسکرین‌شات برای کسی نفرستید.
  • اگر کلید لو رفت، در OpenAI آن را حذف و کلید تازه بسازید.
  • در حساب OpenAI یک سقف ماهانهٔ هزینه بگذارید.
  • اگر کلید در تنظیمات سرور (OPENAI_API_KEY) هم باشد، کلید پنل اولویت دارد.
